# Tech Stack

## Framework and Runtime

- **Application Framework:** Nuxt 4
- **Language/Runtime:** Node.js with TypeScript
- **Package Manager:** pnpm

## Frontend

- **JavaScript Framework:** Vue 3 (via Nuxt 4)
- **CSS Framework:** Tailwind CSS
- **UI Components:** Custom components (no component library)

## Content Management

- **Content Source:** Markdown files in repository
- **Content Module:** Nuxt Content v3
- **CMS Interface:** Nuxt Studio module
- **Version Control:** Git (GitHub)

## Database and Storage

- **Database:** None required
- **Content Storage:** Markdown files in Git repository
- **Media Storage:** Static assets in repository or external CDN

## Deployment and Infrastructure

- **Hosting:** Cloudflare Workers
- **Build:** Nuxt build with Cloudflare preset
- **CDN:** Cloudflare (included with Workers)
- **Domain:** pichot.us (existing)

## Development Tools

- **Linting:** ESLint with Vue/Nuxt configuration
- **Formatting:** Prettier
- **Type Checking:** TypeScript strict mode

## Third-Party Services

- **Authentication:** GitHub OAuth (for Nuxt Studio only)
- **Analytics:** Cloudflare Web Analytics (free)
- **Monitoring:** Cloudflare dashboard
