## CSS on Nuxt

- Use Tailwind CSS 4 and Nuxt UI as the primary styling frameworks.
- Follow the established design system and component library provided by Nuxt UI.
- Avoid adding custom CSS unless absolutely necessary; prefer using Tailwind utility classes and Nuxt UI components.
- Ensure all styles are responsive and adapt well to different screen sizes using Tailwind's responsive design features.
- Maintain consistency in styling by adhering to the project's design tokens for colors, typography, and spacing.
- Optimize CSS for performance by enabling purging/tree-shaking to eliminate unused styles in production builds.
- Document any custom styles or overrides clearly to ensure maintainability and ease of understanding for future developers.
